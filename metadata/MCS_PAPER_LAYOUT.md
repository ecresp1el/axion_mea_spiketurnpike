# Condition-wise figure following the reference layout

Reference inspected directly: [Kochalka et al., Figure 3](https://pmc.ncbi.nlm.nih.gov/articles/PMC13232143/#F3),
specifically panels d–o. The new figure follows the central arrangement:
condition-specific multitrace time courses paired with dot summaries, then
four decoding panels. It replaces the generic metric-wise dashboard as the
preferred visual presentation of this separate temporal analysis.

## Panels a–h: paired time courses and summaries

Each condition occupies a labeled block: Control (a/b), DREADD (c/d), LMO
(e/f), PSAM (g/h). Six fixed metric colors are consistent across conditions:
rate change, fast bursts, burst duration, firing rate, burst delay, burst pause.
These are the same local measurement types documented in
[MCS_TEMPORAL_SIGNATURES.md](MCS_TEMPORAL_SIGNATURES.md).

Measurements have different physical units. Each is therefore transformed as
`(value − pooled pre-stim mean) / pooled pre-stim SD`, with the reference mean
and SD computed over all finite unit/bin values in −10 to 0 s, across all four
groups. The identical transformation applies to every condition and time. This
retains baseline group differences. It differs from the previous dashboard's
own-group-baseline-subtracted heatmaps. The axis is labeled **baseline SD**;
these multitraces are not all event rates in Hz.

Trace panels use the fine display described below around the first STG train,
with a dashed line at zero and a gray 0–5 s summary window. All conditions
share trace limits.
Lines are finite-unit means; bands are pointwise `mean ± 1.96 SEM` normal
approximation intervals. They are not simultaneous or recording-level intervals.

Each summary dot is one unit's finite-bin mean over 0–5 s for that metric.
Duration/delay require a qualifying burst; pause requires two bursts. Missing
bins remain missing rather than zero. Units with no finite post bins for a
measurement are absent for that measurement. Horizontal marks and error bars
show the mean and pointwise 95% interval across those units. Summary-axis
limits adapt to observed unit values, so outlying unit dots remain visible.

### Finer time-course display

Firing rate and rate change use **10-ms spike-count bins**, with Gaussian
sigma **300 ms** applied to each unit separately before aggregation (replacing
the earlier 20-ms display). Pre/post
smoothing is separate and uses reflected boundaries; no response is smoothed
backward across stimulation. The pre reference for firing-rate change remains
that unit's −5 to 0 s rate.

Burst frequency, duration, first-burst delay, and interburst pause use centered
**1-s windows advanced in 50-ms steps**. This supplies a finer display sampling
grid while preserving enough time to measure bursts. It does not create 50-ms
independent observations or 50-ms temporal resolution for burst durations.
Windows are fully inside either pre or post: centers cover −9.5 to −0.5 s
and +0.5 to +9.5 s. The burst curves have no estimates for −0.5 to +0.5 s
and are not connected across that gap. Delay is relative to each window start.
These overlapping-window values now receive Gaussian smoothing with sigma
**300 ms** (six 50-ms steps), separately per unit and per side of stimulation.
The finite-value numerator and finite-value weights are smoothed separately,
then divided. A window with no finite neighboring support remains missing.
This is display-only local averaging, not new burst detection. Effective finite
unit counts in the fine-display table reflect these smoothed estimates; raw
missingness for the statistical summaries and decoder is unchanged. The kernel
is truncated at three sigma (±0.9 s), with reflected boundaries. Rate smoothing
also uses this truncation.

The display retains the exact prior normalization constants and summary dots,
tests, and decoder. Only the time-course sampling changes. To keep the brief
evoked peak and baseline readable together, trace y axes are linear between
−2 and +2 baseline SD and logarithmic outside that range (`symlog`). There is
no artifact blanking; a sharp e-stim peak may include electrical artifacts.
Fine display values and finite unit counts are in `fine_display_time_courses.csv`.
Renderer input is generated by
[refine_mcs_paper_traces.py](../scripts/refine_mcs_paper_traces.py).

Tests compare each actuator to Control for each metric using a Welch test,
with Holm correction across all 18 comparisons. These are post-level
comparisons, not tests of post-minus-pre treatment changes. Stars are
`* p<0.05`, `** p<0.01`, `*** p<0.001`; `ns` means not significant at 0.05.
The CSV includes valid counts, mean differences, and Cohen's d calculated using
the usual pooled within-group sample SD. These newly calculated tests concern
this separate figure and do not replace earlier optimized-window statistics.

## Panels i–l: decoding row

  individual units. Each of 29 unique recordings has a solid colored circle at the
  arithmetic mean of its units’ coordinates. Each group has a larger dark filled
  circle with a bold outline at its unit-weighted centroid; the previous star
  markers are removed. Recording overlays do not change the unit observation
  definition, projection, or statistical weighting.
  The stored model has two axes; a third axis is not fabricated for visual matching.
- **j:** Observed macro same-time held-out-unit AUROC (brown) with a pointwise
  95% class-stratified unit-bootstrap interval. Gray shows a computed unit-label
  shuffled null mean and its pointwise 2.5–97.5 percentile permutation range.
  There are 1,000 refitted label permutations and 1,000 bootstrap samples. The
  former theoretical 0.5 line is replaced by this measured null distribution.
- **k:** Saved row-normalized 0–5 s confusion matrix; one prediction per unit.
  Gray shading and numerical fractions follow the reference's visual convention.
- **l:** Saved cross-time macro AUROC; rows train time, columns test time.
  Reference-style inferno colors run from chance (0.5) to 1. Values below the
  lower color bound saturate; the untruncated matrix remains in the source CSV.

All three temporal decoder panels now use **equal class priors (0.25 each)**.
Their source is `balanced_decoder/`, recomputed with the same six features,
three fixed unit folds, seed, training-only preprocessing, and shrinkage.
Time-resolved AUROC, confusion, and the complete cross-time matrix were all
recomputed; the change is not confined to the confusion matrix. The old

No temporal decoder is retrained inside the composition script itself. The separate
six-feature decoder and the locked 215-feature descriptive projection have

Source paper brain maps and source/sink stimulation panels are not reproduced:

## PSAM assessment and decoder correction

The original six-feature temporal decoder's low PSAM recall is not evidence
that the PSAM data or technology failed. Its class priors track unequal unit
counts (Control 473, LMO 512, PSAM 339, DREADD 230). In a matched diagnostic
using identical three unit folds, features, preprocessing, post windows, and
shrinkage, setting the LDA class priors to 0.25 each changes PSAM recall from
**10.3% to 58.4%**. Overall balanced accuracy rises from **53.6% to 62.7%**;
macro AUROC changes only modestly, **0.833 to 0.838**. PSAM one-versus-rest
AUROC is **0.761** with empirical priors and **0.769** with equal priors.
Thus there is PSAM ranking information that the original argmax decision
rule often assigns to the larger groups. This diagnostic changes the prior
used in LDA fitting as well as its decision rule; it is not simply a new
threshold on the saved original probabilities. It is exploratory, not an
independent held-out confirmation or a replacement decoder.

The original figure displayed the empirical-prior decoder. Following the
explicit request to fix the decoder, the **current figure uses the equal-prior
decoder throughout**: PSAM recall 58.4%, balanced accuracy 62.7%, macro AUROC
0.838 over the averaged 0–5 s predictions. The locked 215-feature LDA remains
unchanged. The earlier diagnostic is retained to explain the change. Audit script:
[audit_psam_temporal_decoder.py](../scripts/audit_psam_temporal_decoder.py).

The underlying activity differences remain: PSAM mean firing increases from
2.857 to 4.657 Hz/unit over mirrored −5–0 and 0–5 s windows (**+1.800 Hz**),
versus Control 2.553 to 7.418 Hz (**+4.864 Hz**). In this separate temporal
summary, PSAM has fewer fast bursts, shorter bursts, and a longer delay than
Control. The mean interburst-pause difference does not survive Holm correction
(adjusted p=0.124). These are e-stim-aligned comparisons, not a direct assay
establishing chemogenetic treatment efficacy or receptor function.

Several local burst features are sparse. PSAM duration is undefined in 78.0%
of the 0–5 s unit/bin cells (Control 71.2%); interburst pause is undefined in
91.4% (Control 91.9%). Median imputation therefore contributes substantially
to the six-feature decoder, especially for pauses. Missing pauses do not mean
zero-length pauses. The conditional plotted means can fluctuate as different
units become measurable. The fine-display CSV records the changing counts.

PSAM comprises 339 units from five recordings, covering Stim 1 and Stim 4 in
this completed-output subset. Its empirical-prior confusion with Control/LMO
occurs in all five recordings, not only one outlier file. This audit does not
establish that biology, expression, sorting, or stimulus delivery is faulty.
PSAM response magnitude is heterogeneous: recording-average firing changes
range from +0.173 to +8.806 Hz/unit. The two largest PSAM recordings contain
214 of 339 units and change by +0.412 and +1.013 Hz/unit, respectively; these
units substantially influence the pooled +1.800 Hz result. The recording with
the largest mean response contains 35 units. This describes the requested
unit-weighted analysis and does not change its observation definition.

## Panel J: shuffled null and observed uncertainty

Generator: [compute_mcs_shuffled_decoder_null.py](../scripts/compute_mcs_shuffled_decoder_null.py).
Outputs in `paper_layout/balanced_decoder/`:

- `panel_j_observed_and_shuffled.csv`: observed AUROC and bootstrap limits,
  shuffled mean/percentile limits, pointwise permutation p, and 20-bin max-T p.
- `panel_j_resamples.npz`: all 1,000 null curves and 1,000 bootstrap curves.
- `panel_j_null_methods.json`: definitions, sources, checksums.

For each permutation, labels are shuffled among units independently within each
of the three fixed fold partitions. This preserves each fold's class counts;
each unit's shuffled label stays the same across all 20 time windows. For every
permutation, all 60 fold/time LDA classifiers are refitted with equal class
priors and shrinkage 0.01. Test labels are permuted too: scoring asks whether
features predict the shuffled identities on held-out units. Training-only
imputation/scaling transforms are cached because they do not depend on labels;
this is identical to recomputing those transforms for each permutation with
fixed data/folds. This is not merely shuffling displayed probabilities.

Observed AUROC is verified against the previously saved equal-prior curve.
For its band, units are resampled with replacement within their four real
classes; one draw of unit identities applies across all times. AUROC is then
recomputed from the existing out-of-fold predictions. These are conditional
pointwise unit-bootstrap intervals: models and feature selection are not
refitted during the bootstrap, and the band is not recording-level uncertainty.
The gray band is a permutation **range**, not a confidence interval for the
null mean. The plotted AUROC curves and both bands are unsmoothed.

Each p value uses `(1 + number of null statistics at least as large as observed)
/ 1001`. Pointwise p values concern individual bins. Max-T p values compare
each null-mean-centered observed AUROC with the largest corresponding centered
null value across all 20 bins, controlling this conditional permutation family.
There are no added significance stars on the figure. The six previously
explored feature types stay fixed: this procedure does not repeat the earlier
feature search, and therefore does not account for that selection history.
Unit-label exchangeability does not establish generalization to new recordings.

Above-null decoding before stimulation indicates pre-existing group/recording
information in these measurements. Above-null decoding after stimulation alone
is not evidence that stimulation created the separability; a change relative
to baseline is a different question. No reference-paper-like increase in
post-stim decoding is imposed on these data.

Reproducibility seeds: fold seed 20261114; permutation seeds 2026111500–2026112499; bootstrap seeds 2026112500–2026113499.

The measured null averages 0.497 across times and permutations. Observed same-time macro AUROC ranges from 0.655 to 0.731 and exceeds this null before as well as after stimulation. All 20 conditional max-T p values are 1/1001; this supports group/recording association in the fixed six-feature representation, not a stimulation-induced gain in separability.
